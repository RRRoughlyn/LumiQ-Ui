# 场景与构图灵感

这组图主要帮助想“画面里可以发生什么”，可以自由拆解、混合和重新设计，不需要照着原图的画法走。

- `IMG_4114.JPG`：蘑菇聚落、棉花般的树冠、巨型植物、人在童话世界里阅读与休息。
- `IMG_4190.JPG`：城市剖面、树洞隐藏门、森林吊灯、云上蒸汽飞行器。
- `IMG_4191.JPG`：河谷城市、热气球、魔毯、云上交通与俯瞰视角。
- `IMG_4201.JPG`：水边的有机建筑群、旅行队伍、生活感前景和明亮远景。
- `IMG_4205.JPG`：深林遗迹、巨型拱门、人物穿越门槛的探索瞬间。
- `IMG_4206.JPG`：大型瀑布盆地、多层水域、微小人物对比出的世界尺度。
- `IMG_4204.PNG`：草原上的巨型白塔、极强的垂直尺度和大片天空。
- `IMG_4203.PNG`：龙脊般的峡谷路线、旅行队伍、鸟瞰式冒险路径。
- `IMG_4202.PNG`：浮空岛文明、分层平台、滑翔翼与环形河流。

使用时可以让构图服务页面任务：例如首页用远景世界和一条清晰旅程线，书库用多个可进入的区域，故事详情用一处明确的门或路径，阅读页则让场景成为故事内容而不是 UI 背景。
