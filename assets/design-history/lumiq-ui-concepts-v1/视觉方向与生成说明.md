# LumiQ Tablet UI 概念试稿 v1

## 视觉母方向

明亮电影童话 × 高级产品界面。

- 保留参考图的电影感、空间纵深、幻想世界入口和精致半透明材质。
- 将大面积深蓝黑改为晨曦天空、珍珠白、低饱和薰衣草紫、柔和桃色和克制香槟金。
- 页面优先保证实际产品信息层级，不采用密集游戏 HUD、赛博霓虹或纯概念插画式布局。
- 三页共享顶部身份区、圆角比例、玻璃材质、光线方向、角色世界观和触控尺度。
- 整体保持低视觉噪声、清洁渐变、清晰文本与安静背景。

## 三张代表性页面

1. `01-home.png`：儿童首页；验证世界观、品牌气质、全局身份与任务优先级。
2. `02-library.png`：故事书库；验证搜索、继续阅读、分类和故事卡片在高信息密度下的清晰度。
3. `03-reader.png`：阅读播放器；验证沉浸故事画面、字幕、播放控制和阅读设置能否共存。

## 生成方式

使用内置 ImageGen，以甲方提供的图片作为风格参考而非编辑底图，三张均为全新完整生成。

## 共同提示词摘要

高保真 4:3 横屏 iPad 产品 UI；LUMIQ 儿童故事与学习平台；明亮欧洲童话电影感；珍珠白玻璃、晨曦蓝、浅薰衣草紫、柔和桃色、香槟金；现代繁体中文排版；大触点和清楚层级；深蓝只作小面积对比；避免黑色全屏、赛博霓虹、游戏 HUD、过度发光、密集闪粉、杂乱组件和不可读小字。

## 第一轮判断重点

按顺序判断：视觉方向是否符合品牌 → 页面结构和信息主次是否正确 → 三页是否像同一个产品 → 最后才讨论颜色浓淡、圆角或小装饰。
