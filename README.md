这是 LumiQ 儿童童话阅读 iPad 软件的设计交接仓库，包含需求逻辑、设计决策、阶段图、最新母版和参考素材。

1. 阅读 `docs/PROJECT_CONTEXT.md` 了解甲方需求与页面逻辑。
2. 阅读 `docs/DECISION_LOG.md` 了解已经确认和放弃的方向。
3. 最新首页基准：`assets/latest-master/lumiq-home-master.png`。
4. 新增场景灵感：`references/composition-elements/`。
5. 飞书完整文档：https://hcnbsg6ttb3t.feishu.cn/docx/ILXMdSmCHoYn8lxqqsbca6sCn5d

## 当前核心方向

- iPad 横屏软件界面，不按普通网页思路设计。
- UI 文案使用英文。
- 童话世界要复杂、精细、有远近层次，但整体明亮、柔和，不暗黑。
- 先抓住底层信息逻辑，再决定按钮、卡片和板块的表面形式。
- 页面之间保持同一产品的导航、字体、材质和交互语言，但构图不需要张张一样。

`assets/design-history/` 保留了大量阶段性探索，方便了解演进过程；不要默认把上一轮生成图当成下一轮母版，除非任务明确指定。
