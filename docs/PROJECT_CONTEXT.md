# 项目背景与底层逻辑

## 项目目标

为 LumiQ 儿童童话阅读产品完成一套横屏 iPad UI 效果图。工程功能已经基本存在，当前工作的核心是重新梳理视觉表达，同时保留正确的信息层级和使用流程。

## 甲方真实诉求

- 不是重新开发 App，而是为已有功能建立一套更好看的 UI 风格。
- 旧录屏的信息层级可以参考，但画面质感不满意。
- 甲方希望有冒险感、高级感、欧美童话感和电影场景感。
- 不要阴森、暗黑或压得很沉；即使使用紫蓝色，也要有柔和光线、空气感和清晰层级。
- 面向儿童，界面要容易理解、可触达、有趣，但不能堆满图标和装饰。
- 首页首先应让儿童知道“我可以进入故事、继续阅读或探索故事”，不是展示所有功能。

## 设计判断原则

1. 先定义页面的用户任务与必要信息，再决定按钮、卡片或板块形式。
2. 录屏中的控件只是现有实现，不代表新设计必须一一复制。
3. 大图建立世界观，UI 负责引导；不要让导航和按钮压过画面主角。
4. 同一套产品要保持导航与材质一致，但不同功能页应有不同构图和信息密度。
5. 英文 UI、横屏 iPad 比例、儿童触控尺寸和家长入口的边界要贯穿全套。

## 推荐页面体系

### 1. Home

核心任务：进入故事世界、继续上次阅读、找到故事书库。必要信息包括品牌、主要入口、用户状态；家长区、语言与设置可放在较弱层级。

### 2. Story Library

核心任务：找到一本想读的故事。必要信息包括搜索、分类或筛选、故事封面、阅读状态；推荐、收藏和下载是辅助信息。

### 3. Story Detail

核心任务：判断是否开始阅读。必要信息包括故事名称、封面或主视觉、简短简介、年龄/时长等关键信息、开始或继续阅读；个性化玩法可作为次级入口。

### 4. Reader

核心任务：沉浸阅读并进行最少必要控制。必要信息包括故事内容、页码/进度、上一页下一页或播放；旁白、语言、语速、音量和阅读模式需要可调，但默认收起。

### 5. Onboarding / Account / Parent

可能包含语言选择、家长 PIN、兑换码/订阅、儿童档案、设备连接、权限与完成状态。每一步只解决一个明确任务，并持续显示进度。

## 品牌与视觉方向

- 复杂精细的童话世界，但控制噪点与无意义小装饰。
- 有前景、中景、远景，场景具备旅行感、探索感和空间尺度。
- 柔和晨曦、粉紫、天蓝、奶油白、温暖金色是优先色域。
- 可以出现城堡、书本、云海、桥梁、瀑布、花园、遗迹、浮岛、飞行器或其他冒险元素。
- 吉祥物小鸟不是必须项；只有在叙事与构图需要时使用。
