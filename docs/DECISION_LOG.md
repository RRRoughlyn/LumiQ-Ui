# 设计决策记录

## 已确认

- 页面比例使用横屏 iPad，当前基准图为 1586×992。
- 所有 UI 文案使用英文。
- 视觉需要梦幻、柔和、明亮，同时比早期简陋方案更复杂、更精细。
- 首页可借鉴乙女游戏主界面的世界观建立方式，但必须保留儿童阅读软件的清晰任务。
- Peter Rabbit 官网式的英伦绘本、水彩、留白和纸张感曾得到较好反馈。
- 最新阶段更偏复杂童话魔法场景，并强调远景层次和降低 AI 劣质感。
- 首页导航由底部移至顶部；底部大导航过于抢镜。
- 主 CTA 保持单一、直接，不再叠加多层卡片和按钮。
- 最新母版中下方标题和 CTA 上移少量，并删除第三行继续阅读小字。

## 需要避免

- 不要照搬甲方旧录屏的表面控件。
- 不要每一页都用同一套固定卡片排版。
- 不要把图标、导航、装饰和按钮堆满画面。
- 不要暗黑、阴森、低亮度或深蓝紫压满全屏。
- 不要默认沿用上一轮生成图；每轮按新要求和指定参考重新判断。
- 不必固定使用小红帽，也不必固定使用小鸟。
